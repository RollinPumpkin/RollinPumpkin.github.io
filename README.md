## 🛠️ Cara Deploy ke GitHub Pages (Gratis Selamanya)

### Langkah 1: Buat Repositori di GitHub
1. Buka [github.com/new](https://github.com/new).
2. Beri nama repositori persis seperti ini:
   ```text
   RollinPumpkin.github.io
   ```
   *(Harus persis sama dengan username GitHub Anda agar domain `https://rollinpumpkin.github.io` langsung aktif otomatis).*
3. Set visibilitas ke **Public**.
4. Biarkan centang "Add a README file" kosong (karena kita sudah punya kodenya).
5. Klik **Create repository**.

### Langkah 2: Push Kode dari Komputer
Buka terminal (PowerShell atau Git Bash) di folder proyek ini:
```bash
cd "C:\Users\septa\.gemini\antigravity\scratch\rollinpumpkin.github.io"

# Inisialisasi git jika belum
git init
git add .
git commit -m "feat: initial commit modern bento portfolio website"

# Hubungkan ke repositori GitHub Anda
git branch -M main
git remote add origin https://github.com/RollinPumpkin/RollinPumpkin.github.io.git
git push -u origin main
```

### Langkah 3: Selesai!
Tunggu sekitar 1–2 menit, website Anda akan langsung tayang secara global di:
👉 **`https://rollinpumpkin.github.io`**
