Microservices Next.js 16 (React 19) FastAPI (Python) Supabase Realtime PostgreSQL Random Forest ESP32 IoT

Sistem Pemantauan Kebocoran Arus Transformator Multichannel untuk Predictive Maintenance (PLN)

Sistem ini dirancang dengan pemisahan antarmuka web dan layanan Model Machine Learning agar keduanya dapat dikembangkan secara independen. Data dari 9 kanal sensor kelistrikan dikirim secara real-time lewat WebSocket dengan latensi ~85 ms tanpa packet loss. Model Random Forest dipakai untuk meramalkan kondisi jaringan 24 jam ke depan menggunakan sliding window 12 jam, sekaligus memberi rekomendasi mitigasi fisik untuk mencegah terjadinya loncatan api (flashover).
